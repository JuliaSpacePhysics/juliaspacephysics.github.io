GeoCotrans.jl compared with IRBEM and PySPEDAS

GeoCotrans.jl is a native Julia implementation of geocentric coordinate transformations and IGRF field line tracing. Here we check it against IRBEM.jl (Fortran) and PySPEDAS (Python), and benchmark the three.

NoteTakeaway

GeoCotrans agrees closely with IRBEM and PySPEDAS and is an order of magnitude faster. It interpolates IGRF coefficients and the Sun’s direction more finely, which accounts for the small differences.

Code 
using GeoCotrans, IRBEM
using PySPEDAS, PySPEDAS.PythonCall
using DimensionalData, Dates, Chairmarks, Test
using OrdinaryDiffEqTsit5

irbem_cotrans(pos, in, out) = coord_trans(in, out, collect(dims(pos, Ti)), parent(pos)')'

Field line tracing and magnetic equator

GeoCotrans.find_magequator traces the field line through a point and locates the |B| minimum, like IRBEM’s find_magequator with IGRF only (kext = 0).

Code 
t = DateTime(2020, 1, 1)
pos = GEO(3.0, 0.5, 1.2)
jl_eq = GeoCotrans.find_magequator(pos, t, Tsit5())
ir_eq = IRBEM.find_magequator(t, pos; kext = 0)
@test jl_eq.pos ≈ ir_eq.XGEO rtol = 1e-3
@test jl_eq.Bmin ≈ ir_eq.Bmin rtol = 1e-3

[GeoCotrans.jl](https://juliaspacephysics.github.io/GeoCotrans.jl/dev/) is a native Julia implementation of geocentric coordinate transformations and IGRF field line tracing.
Here we check it against [IRBEM.jl](https://juliaspacephysics.github.io/IRBEM.jl/dev/) (Fortran) and [PySPEDAS](https://github.com/spedas/pyspedas) (Python), and benchmark the three.

::: {.callout-note}
## Takeaway
GeoCotrans agrees closely with IRBEM and PySPEDAS and is an order of magnitude faster. It interpolates IGRF coefficients and the Sun's direction more finely, which accounts for the small differences.
:::

```{julia}
#| output: false
using GeoCotrans, IRBEM
using PySPEDAS, PySPEDAS.PythonCall
using DimensionalData, Dates, Chairmarks, Test
using OrdinaryDiffEqTsit5

irbem_cotrans(pos, in, out) = coord_trans(in, out, collect(dims(pos, Ti)), parent(pos)')'
```

## Field line tracing and magnetic equator

`GeoCotrans.find_magequator` traces the field line through a point and locates the |B| minimum, like IRBEM's `find_magequator` with IGRF only (`kext = 0`).

```{julia}
t = DateTime(2020, 1, 1)
pos = GEO(3.0, 0.5, 1.2)
jl_eq = GeoCotrans.find_magequator(pos, t, Tsit5())
ir_eq = IRBEM.find_magequator(t, pos; kext = 0)
@test jl_eq.pos ≈ ir_eq.XGEO rtol = 1e-3
@test jl_eq.Bmin ≈ ir_eq.Bmin rtol = 1e-3
```

```{julia}
@b GeoCotrans.find_magequator($pos, $t, Tsit5()), IRBEM.find_magequator($t, $pos; kext = 0)
```

Tracing the whole field line:

```{julia}
@b trace($pos, $t, Tsit5()), IRBEM.trace_field_line($t, $pos; kext = 0)
```
